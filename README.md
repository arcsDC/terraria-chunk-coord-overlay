# terraria-chunk-coord-overlay

A tModLoader mod that displays the player's current chunk coordinates in the top-left corner for easier world navigation.

## Stack

Primary language: **C#**

## Project structure

- `ChunkCoordOverlayMod.cs` — Draws current chunk coordinates on the screen for navigation.
- `build.txt` — mod metadata

## Usage

Review the source files and install any dependencies referenced by the project before running it.
